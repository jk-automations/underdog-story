# Preset: small-business-rescue-bakery ("The Last Croissant", v6)

The 12 scenes and lines live in `preset.json` (generated by `tools/write_preset.py`; edit that file, then rerun it).

Reference sheets are **not** in this repo. Put your own sheets here, in `assets/` (git-ignored):

| File | What it shows |
|---|---|
| `assets/owner.png` | the baker (character sheet) |
| `assets/rival.png` | the rival (character sheet) |
| `assets/partner.png` | the partner (character sheet) |
| `assets/hero1.png` | hero 1: black-and-green STRIPED shirt, wavy hair, beard |
| `assets/hero2.png` | hero 2: plain BLACK t-shirt, curly hair, thin moustache |
| `assets/location.png` | the bakery interior / storefront |

Then `python3 tools/stage_preset.py --input-dir <ComfyUI>/input` copies them into ComfyUI's input folder as
`underdog_<role>.png` and writes `workflows/underdog-story-<preset>.json` with those images already picked.
Only use sheets of fictional characters, or of real people who gave you written permission.
