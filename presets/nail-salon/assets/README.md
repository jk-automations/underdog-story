# Character sheets for this preset

Same set as `presets/barber-shop/assets/README.md`: `owner.png`, `rival.png`, `regular.png`, `location.png`,
`rival_store.png` (the rival sign reads exactly the preset's `rival_brand`). The looks are in `../preset.json` under
`cast` and `slots`. Hero 1 and hero 2 come from the bakery sample. Without sheets the app still runs (Nano Banana draws
from the descriptions), but faces will drift between scenes. Check: `python3 tools/stage_preset.py --preset nail-salon --check`.
